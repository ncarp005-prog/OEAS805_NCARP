How do I indicate that the text contents should go to the next line?

CLAUDE:
In PowerShell, inside a double-quoted string you use the backtick-n escape sequence: `n -- that's a backtick followed by the letter n. PowerShell treats the backtick as its escape character (like \ in many other languages).

Example:

"First line`nSecond line`nThird line" | Out-File HW1_ncarp.txt

That will produce a file with three separate lines.

A couple of related notes:

- It must be a double-quoted string ("..."). Single-quoted strings ('...') treat everything literally, so `n won't be interpreted as a newline there.
- If you're writing a lot of multi-line text, it's often easier to use a here-string instead of stacking `n characters:

@"
First line
Second line
Third line
"@ | Out-File HW1_ncarp.txt

A here-string starts with @" followed by a newline, and ends with "@ on its own line (make sure the closing "@ is at the very start of the line, no leading spaces). This lets you just type normally across multiple lines in the terminal and it preserves the line breaks automatically.
